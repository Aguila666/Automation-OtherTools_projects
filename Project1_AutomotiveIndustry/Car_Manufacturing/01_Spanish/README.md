# Exercise 1: Spanish**



**Tarea:** Análisis de Datos + Machine Learning + Automatización con Airflow + Uso de Power BI



**Objetivo:**



Desarrolla un sistema automatizado que realice el análisis de datos utilizando un modelo de Machine Learning. Utiliza Apache Airflow para gestionar el flujo de trabajo y automatizar el proceso de análisis. Además, crea un informe visual con Power BI.



**Herramientas:**



- **Apache Airflow:** Para la orquestación de flujos de trabajo.

- **Machine Learning:** Usar Pandas y Scikit-learn para preprocesar los datos y entrenar un modelo.

- **Power BI:** Para generar un informe visual con los resultados del análisis.



**Pasos:**



1. Preparación de los datos: Preprocesa los datos con Pandas y NumPy para el análisis de Machine Learning.

2. Entrenamiento del modelo: Usa un modelo adecuado como Regresión Lineal o Clasificación en Scikit-learn.

3. Automatización: Crea un flujo de trabajo automatizado con Apache Airflow que ejecute el modelo y genere informes.

4. Visualización: Usa Power BI para mostrar los resultados del modelo entrenado, visualizando métricas clave.



**Resultado Esperado:**



Un flujo de trabajo automatizado que procese los datos, entrene un modelo de Machine Learning y genere un informe visual utilizando Apache Airflow y Power BI.
